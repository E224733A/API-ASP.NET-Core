# Resultats des tests API Mobile SLI v1.2

Ce fichier est un modele de resultat manuel.

Le rapport reel est genere automatiquement par :

```powershell
.\scripts\run-api-mobile-tests.ps1 -ApiBaseUrl "http://192.168.1.233:5000"
```

Rapport genere :

```text
rapports\rapport-tests-api-mobile.md
```

CSV genere :

```text
rapports\resultats-tests-api-mobile.csv
```

JSON genere :

```text
rapports\resultats-tests-api-mobile.json
```
